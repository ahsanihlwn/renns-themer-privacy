Renns Themer adalah aplikasi utilitas untuk memasang file tema kustom (.xth / .zth) pada perangkat Transsion (Infinix/Tecno/itel). Halaman ini menjelaskan data apa yang diakses aplikasi ini dan bagaimana data tersebut digunakan.

Ringkasan singkat: Renns Themer tidak mengumpulkan atau menyimpan data pribadi Anda di server milik kami. Fitur inti aplikasi (memasang dan mengelola file tema) sepenuhnya berjalan di perangkat Anda tanpa koneksi internet. Aplikasi ini menampilkan iklan banner melalui Google AdMob, yang dapat mengumpulkan data terbatas (lihat bagian "Iklan" di bawah) sesuai kebijakan privasi Google sendiri.

Data yang Diakses Aplikasi

Untuk memasang dan mengelola file tema, aplikasi memerlukan akses ke:

  • File tema yang Anda pilih (.xth / .zth) — dibaca untuk disalin ke folder tema aplikasi launcher/tema Transsion di perangkat Anda.
  • Folder data aplikasi launcher/tema Transsion (mis. Android/data/com.transsion.theme/files/) — diakses melalui Shizuku atau akses root, khusus untuk menyalin, membaca metadata, dan menghapus file tema yang Anda kelola sendiri di dalam aplikasi ini.

Semua pemrosesan ini terjadi sepenuhnya di perangkat Anda. Tidak ada file, metadata, maupun informasi lain yang dikirim keluar dari perangkat Anda oleh aplikasi ini.

Iklan

Halaman "Tentang" pada aplikasi menampilkan satu banner iklan yang disediakan oleh Google AdMob. Untuk menampilkan iklan yang relevan, Google AdMob dapat mengumpulkan data seperti ID iklan perangkat, informasi perangkat umum, dan data interaksi dengan iklan. Data ini dikelola oleh Google, bukan oleh kami, dan tunduk pada Kebijakan Privasi Google serta Kebijakan Data Pengguna Google AdMob. Kami tidak memiliki akses ke data yang dikumpulkan Google AdMob dan tidak menggunakannya untuk tujuan lain apa pun.

Fitur inti aplikasi (memasang dan mengelola file tema) tidak terpengaruh oleh iklan ini dan tetap berjalan sepenuhnya di perangkat Anda seperti dijelaskan di atas.

Data yang TIDAK Dikumpulkan (di Luar Iklan)

  • Tidak ada nama, email, nomor telepon, atau data identitas pribadi lainnya.
  • Tidak ada data lokasi.
  • Tidak ada riwayat penggunaan, statistik, atau data analitik dari kami sendiri.
  • Tidak ada SDK pelacakan pihak ketiga selain Google AdMob untuk iklan (lihat bagian "Iklan" di atas).
  • Tidak ada akun pengguna atau proses login.

Izin yang Digunakan

Aplikasi ini dapat meminta izin berikut:

  • Akses penyimpanan / manajemen file — untuk membaca file tema yang Anda pilih dan menyalinnya ke folder tujuan yang sesuai.
  • Shizuku (opsional, jika Anda memasang aplikasi Shizuku secara terpisah) — untuk menjalankan operasi salin/hapus file pada folder aplikasi launcher/tema lain, yang tidak dapat diakses langsung oleh aplikasi biasa karena kebijakan penyimpanan terbatas (scoped storage) Android.
  • Akses internet — digunakan semata-mata oleh Google AdMob untuk memuat banner iklan pada halaman "Tentang" (lihat bagian "Iklan" di atas). Fitur inti aplikasi tidak menggunakan izin ini.

Renns Themer is a utility app for installing custom theme files (.xth / .zth) on Transsion devices (Infinix/Tecno/itel). This page explains what data the app accesses and how it's used.

Short version: Renns Themer does not collect or store your personal data on any server we control. The app's core function (installing and managing theme files) runs entirely on your device with no internet connection. The app shows a banner ad through Google AdMob, which may collect limited data (see the "Advertising" section below) under Google's own privacy policy.

Data the App Accesses

To install and manage theme files, the app needs access to:

  • The theme file you pick (.xth / .zth) — read in order to copy it into your Transsion launcher/theme app's theme folder.
  • The Transsion launcher/theme app's data folder (e.g. Android/data/com.transsion.theme/files/) — accessed through Shizuku or root access, solely to copy, read metadata from, and delete the theme files you manage inside this app.

All of this processing happens entirely on your device. No file, metadata, or other information is ever sent off your device by this app.

Advertising

The app's "About" page displays a single banner ad served by Google AdMob. To show relevant ads, Google AdMob may collect data such as your device's advertising ID, general device information, and ad interaction data. This data is handled by Google, not by us, and is governed by Google's Privacy Policy and the Google AdMob User Data Policy. We do not have access to the data Google AdMob collects and do not use it for any purpose of our own.

The app's core function (installing and managing theme files) is unaffected by this ad and continues to run entirely on your device as described above.

Data NOT Collected (Outside of Advertising)

  • No name, email, phone number, or other personal identity data.
  • No location data.
  • No usage history, statistics, or analytics data of our own.
  • No third-party tracking SDKs other than Google AdMob for advertising (see "Advertising" above).
  • No user accounts or login process.

Permissions Used

The app may request the following permissions:

  • Storage / file access — to read the theme file you pick and copy it to the appropriate destination folder.
  • Shizuku (optional, if you separately install the Shizuku app) — to run copy/delete file operations against another app's data folder, which a regular app can't reach directly under Android's scoped storage restrictions.
  • Internet access — used solely by Google AdMob to load the banner ad on the "About" page (see "Advertising" above). The app's core function does not use this permission.

External Links

The app's "About" page includes a link to the developer's YouTube channel. That link opens your browser/the YouTube app outside of Renns Themer and is governed by YouTube/Google's own privacy policy, not this one.

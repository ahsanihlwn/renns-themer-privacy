Kebijakan Privasi

Renns Themer

Berlaku mulai 29 Juli 2026

Renns Themer adalah aplikasi utilitas untuk memasang file tema kustom (.xth / .zth) pada perangkat Transsion (Infinix/Tecno/itel). Halaman ini menjelaskan data apa yang diakses aplikasi ini dan bagaimana data tersebut digunakan.

Ringkasan singkat: Renns Themer tidak mengumpulkan, menyimpan, atau mengirim data pribadi Anda ke server mana pun. Aplikasi ini tidak memiliki koneksi internet dan tidak menyertakan SDK analitik, iklan, atau pelacakan pihak ketiga apa pun.

Data yang Diakses Aplikasi

Untuk memasang dan mengelola file tema, aplikasi memerlukan akses ke:

  • File tema yang Anda pilih (.xth / .zth) — dibaca untuk disalin ke folder tema aplikasi launcher/tema Transsion di perangkat Anda.
  • Folder data aplikasi launcher/tema Transsion (mis. Android/data/com.transsion.theme/files/) — diakses melalui Shizuku atau akses root, khusus untuk menyalin, membaca metadata, dan menghapus file tema yang Anda kelola sendiri di dalam aplikasi ini.

Semua pemrosesan ini terjadi sepenuhnya di perangkat Anda. Tidak ada file, metadata, maupun informasi lain yang dikirim keluar dari perangkat Anda oleh aplikasi ini.

Data yang TIDAK Dikumpulkan

  • Tidak ada nama, email, nomor telepon, atau data identitas pribadi lainnya.
  • Tidak ada data lokasi.
  • Tidak ada riwayat penggunaan, statistik, atau data analitik.
  • Tidak ada iklan maupun SDK pelacakan pihak ketiga.
  • Tidak ada akun pengguna atau proses login.

Izin yang Digunakan

Aplikasi ini dapat meminta izin berikut, hanya untuk fungsi intinya memasang tema:

  • Akses penyimpanan / manajemen file — untuk membaca file tema yang Anda pilih dan menyalinnya ke folder tujuan yang sesuai.
  • Shizuku (opsional, jika Anda memasang aplikasi Shizuku secara terpisah) — untuk menjalankan operasi salin/hapus file pada folder aplikasi launcher/tema lain, yang tidak dapat diakses langsung oleh aplikasi biasa karena kebijakan penyimpanan terbatas (scoped storage) Android.

Tautan Eksternal

Halaman "Tentang" pada aplikasi menyertakan tautan ke kanal YouTube pembuat aplikasi. Tautan ini membuka browser/aplikasi YouTube di luar Renns Themer dan tunduk pada kebijakan privasi YouTube/Google sendiri, bukan kebijakan ini.

Perubahan pada Kebijakan Ini

Jika kebijakan ini berubah di masa mendatang, pembaruan akan dipublikasikan di halaman ini dengan tanggal berlaku yang diperbarui.
